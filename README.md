### About me

I'm Pranav, a software engineer. Most of my work is on the backend with Python (FastAPI, Django) and Go, and I build frontends in React and TypeScript. Lately I've been playing with workflow automation and AI-backed apps, and I practise DSA on NeetCode most days. Always happy to talk about interesting projects.
